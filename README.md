# ☠ One Piece Wiki

Uma Wiki interativa de One Piece desenvolvida com React + Vite, utilizando APIs para exibir personagens, Akuma no Mi e arcos da obra.

---

# ✨ Preview

## 🔥 Funcionalidades

- 👤 Lista de personagens
- 🍎 Lista de Akuma no Mi
- 🗺 Arcos e sagas
- 🔎 Barra de pesquisa
- 🎨 Interface moderna inspirada em streaming/anime
- 📱 Responsivo para mobile
- ⚡ Projeto rápido com Vite

---

# 🛠 Tecnologias Utilizadas

- React
- Vite
- JavaScript
- CSS3
- API One Piece

---

# 📦 Instalação

Clone o repositório:

```bash
git clone LINK_DO_REPOSITORIO
```

Entre na pasta:

```bash
cd nome-do-projeto
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```
